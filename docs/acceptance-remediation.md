## 已整改

- 备份冲突导入时明确区分源题库 ID 和目标 ID，图片进入新题库，原题库不被误回填。
- 备份解压前进行路径、文件白名单、重复、加密和大小预检，使用经过检查的文件名单解压。
  上限：ZIP 128 MB / 解压合计 256 MB / 单文件 32 MB / 20,000 条目 / 500 个题库。
  所有源内容和清单关联先验证，再开始安装；未知/缺失题库源不再静默跳过。
- release 构建缺少 keystore 时失败；发布脚本强制校验包信息和项目证书指纹，
  已有 tag 必须指向 HEAD，并附带第三方许可文件。
- CI 增加 Android 干净 Debug 构建、发布策略功能测试、许可清单一致性检查及安全公告判定。
- 类型检查纳入 `App.tsx` 和根入口；统一 0.1.0、Node 22.13+、pnpm 11 要求。
- pnpm 11 的 hoisted 配置迁至工作区 YAML，解决 Windows CMake 260 字符路径错误。
- AI 调用限时 60 秒，模型列表/更新检查限时 30 秒，响应体读取也受限；文本抽取可取消。
  原生 APK 文件下载仍使用 FileSystem 原生下载接口，未新增下载取消控件。
- 安全存储失败明确报错，旧凭据迁移失败时保留原副本供下次重试。
- 修复测试缺少 await 的异步警告；补充远程图片联网行为、举报方式、发布实际流程和许可文本。
