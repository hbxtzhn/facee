## 一句话
volatile-* 系列只在设置了过期时间的 key 中淘汰，allkeys-* 在全部 key 中淘汰。

## 要点
- [kp1|2] volatile-lru、volatile-lfu、volatile-random、volatile-ttl 只看带过期的 key
- [kp2] allkeys-* 系列在全部 key 中挑选
- [kp3] noeviction 不淘汰任何 key，内存满时拒绝写入

## 详解
`volatile-` 前缀表示候选集合是过期字典，`allkeys-` 前缀表示候选集合是全部 key。`volatile-ttl` 优先淘汰剩余寿命最短的 key。`noeviction` 不淘汰，所以选项 d 不对。

## 选项
- [a] volatile-lru ✓
- [b] allkeys-lfu
- [c] volatile-ttl ✓
- [d] noeviction
